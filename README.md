# 🌐 My E-Portfolio Website

เว็บไซต์แฟ้มสะสมผลงานออนไลน์ (E-Portfolio) สำหรับนำเสนอประวัติส่วนตัว ผลงาน กิจกรรม และความสามารถด้านเทคโนโลยีและการเขียนโปรแกรม

## 📌 รายละเอียดโปรเจกต์

เว็บไซต์นี้จัดทำขึ้นเพื่อรวบรวมข้อมูลส่วนตัวและนำเสนอผลงานในรูปแบบออนไลน์ โดยออกแบบให้มีความเรียบง่าย สวยงาม และใช้งานง่าย รองรับการเปิดใช้งานทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

## 🛠️ เทคโนโลยีที่ใช้

- **HTML** ใช้สร้างโครงสร้างเว็บไซต์
- **CSS** ใช้ตกแต่งเว็บไซต์และจัดรูปแบบหน้าตา
- **JavaScript** ใช้เพิ่มการทำงานและการโต้ตอบภายในเว็บไซต์

## 📂 ส่วนประกอบของเว็บไซต์

1. **Home** – หน้าแรกและข้อความต้อนรับ
2. **About Me** – แนะนำตัวและประวัติส่วนตัว
3. **Portfolio** – แสดงผลงานและโปรเจกต์ต่าง ๆ
4. **Activities** – แสดงกิจกรรมและประสบการณ์
5. **Contact** – ช่องทางติดต่อและแบบฟอร์มส่งข้อความ

## 🚀 วิธีเปิดใช้งาน

1. ดาวน์โหลดหรือ Clone โปรเจกต์นี้
2. เปิดไฟล์ `index.html`
3. ใช้เว็บเบราว์เซอร์ เช่น Google Chrome เพื่อเข้าชมเว็บไซต์

## ✏️ การแก้ไขข้อมูล

สามารถแก้ไขข้อมูลส่วนตัว ผลงาน กิจกรรม และช่องทางการติดต่อได้โดยแก้ไขข้อความภายในไฟล์ `index.html`

## 🎨 การออกแบบ

- ใช้โทนสีฟ้าและสีขาว
- รูปแบบเว็บไซต์เรียบง่ายและทันสมัย
- มีเมนูนำทางไปยังแต่ละส่วน
- รองรับการแสดงผลบนอุปกรณ์หลายขนาด
